IanLangs

IanLangs es una organización enfocada en la creación de micro-lenguajes, supersets y herramientas experimentales para desarrollo real.

No son demos: son lenguajes, transpiladores y utilidades pensadas para usarse.

Proyectos principales

  • Cognalian — Lenguaje de programación implementado en Python. repositorio
  • IPM — Ian Package Manager. Gestor de paquetes minimalista para proyectos IanLangs. repositorio
  • FLOW C++ — C++ superset. primer paquete que esta para rpm! (en icc) repositorio
