IanLangs

Que es?

IanLangs es una organización dedicada a la creación de micro lenguajes simples o complejos.

Hay supersets, lenguajes basados en otros, object notations, etc.

Algunos proyectos

  • IanLangs.github.io: Página principal de IanLangs.
  • github de IanLangs: Codigos fuente de IanLangs.
  • cognalian: lenguaje de programación basado e implementado en python.
  • ian object notation: object notation basado en yaml.
  • PMAKE: forma de declarar constantes, ejecutar comandos de una linea en bash sin saber detectar args

Y muchos más proyectos parados o en desarrollo.
