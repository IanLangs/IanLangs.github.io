Manual de Flow-C++

Referencia completa de tipos, keywords y estructuras de Flow-C++

1. Tipos fundamentales

  • str – String gestionado por Flow-C++.
  • wstr – String wide (Unicode).
  • any – Contenedor genérico para cualquier valor.
  • anyP – Equivalente a shared_ptr<any>.

str mensaje = "hola";
wstr wmensaje = L"hola";
any a = 42;
any b = str("hello");
anyP ptr = std::make_shared<any>(b);

2. Casting y comprobación de tipos

2.1 [x]:T:

Cast directo (inseguro) a tipo T. Útil cuando estás seguro del tipo.


any b = str("hello");
str s = [b]:str:;

2.2 [x]:T:?

Comprueba en runtime si x es del tipo T.


any a = 42;
if ([a]:int:?) {
    println("a es int");
    int n = [a]:int:;
}

3. Defer

Ejecuta código al final del scope en orden inverso. Sintaxis: defer código;;


auto d1 = defer println("Deferred 1");;
auto d2 = defer println("Deferred 2");;

4. Tagged union

Permite un tipo que puede contener una de varias variantes con tag y value.


tagged union[2] Resultado<int, int> {Ok, Err}

Resultado r;
r = Resultado::Err;
r = -1;

switch(r) {
    case Resultado::Ok:
        println("Ok = ", r.value.Ok);
        break;
    case Resultado::Err:
        println("Err = ", r.value.Err);
        break;
}

5. Funciones


template <typename T>
fn make_any(T x) -> any {
    return x;
}

6. Loops y condicionales

Flow-C++ soporta for, while, if, until y unless.


int total = 0;
for(int i = 1; i <= 5; i++) {
    total += i;
}

until(total > 10) {
    total += 1;
}

unless(total > 20) {
    println("Sigue dentro del rango");
}

7. Switch / Case

Funciona como C++ y permite usar tagged unions.


switch(r) {
    case Resultado::Ok:
        println("Ok = ", r.value.Ok);
        break;
    case Resultado::Err:
        println("Err = ", r.value.Err);
        break;
}

type StrVector = std::vector<str>

9. Otros keywords

  • Cfn – Función con linkage C (extern "C").
  • loop – Bucle infinito (while(true)).
  • pub class – Clase 100% pública.
