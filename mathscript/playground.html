Guía rápida de MathScript

  • fn: define funciones (equivale a function).
  • mut / immut: Variables mutables e inmutables.
  • ::tipado: Notación decorativa.
  • using(): transpila a require(), ignorado en navegador.

Cambios respecto a JS

  • Tipado opcional.
  • Variables mutables e inmutables gestionadas vía objetos.
  • Funciones definidas con fn.

Cosas que funcionan pero no se recomiendan

  • Redefinir variables o funciones sin IIFE.
  • Usar using() en navegador. Este si puede dar error
  • Dependencia de eval para ejecución.
