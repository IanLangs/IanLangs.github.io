MathScript - Documentación Oficial

Introducción

MathScript (MS) es un superset de JavaScript que añade variables mutables e inmutables, funciones simples y tipado opcional.

Cambios respecto a JavaScript

  • fn: define funciones (equivale a function).
  • mut / immut: Variables mutables e inmutables con .get() y .set().
  • Tipado opcional (::tipo): decorativo, no cambia ejecución.
  • using(...): transpila a require(...). Solo funciona en Node.js; no sirve en el navegador, version para playgrounds ni si quiera lo transpila.

Cosas que funcionan pero no se recomiendan

  • Redefinir funciones o variables en el mismo scope sin IIFE puede causar errores.
  • Usar using() en navegador no hace nada.
  • Depender de eval para ejecución.

Instalación con npm


# Instalar MathScript
npm install @ianlangs/mathscript --save

# Transpilar archivos con archivo de configuracion
msc --init archivo1.ms archivo2.ms
msc # o msc msconfig.json


# sin archivo de configuración
msc --transpile archivo1.ms archivo2.ms # en vez de --transpile se puede usar -t

# O si quierers ejecutar un archivo
ms-node archivo1.ms # los imports o require deben estar ya transpilados a js

MS package manager


mpm -n <package> # npm install package
mpm -i <package> # curl -fsSL https://ianlangs.github.io/mpm-ms/<package>.ms -o ./ms_modules/<package>
mpm -i -c <url> # curl -fsSL url
